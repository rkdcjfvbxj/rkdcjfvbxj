## Featured Project

### 🩸 BloodOps | 헌혈 서비스 웹 애플리케이션

헌혈자와 의료진이 이용하는 기능을 연결한 풀스택 팀 프로젝트입니다.  
헌혈 과정의 편의성과 의료진의 관리 업무를 함께 고려했습니다.

**Java · Spring Boot · React · MariaDB · ECharts · Jsoup**

| 주요 작업 | 구현·개선 내용 |
| :--- | :--- |
| 혈액 보유 현황 | 공개 데이터 수집, 혈액 제제별 보유일수·보유율 시각화, 수급 위기 단계 안내 |
| 포인트 보상 | 헌혈 포인트 상품 구매, 실물 수령 코드·기한 관리, 디지털 상품권 코드 배정 |
| 전자문진 | 회원·비회원 문진, 나이·체중 검증, 예약·센터 연계 및 의료진 조회 개선 |
| 증명서 | 조회용·제출용 구분, 발급번호 기반 진위 확인, 중복 발급 방지 |
| 운영 기능 | 프로모션 관리, Q&A 관리자 답변, FAQ 및 센터별 조회 개선 |

**개발하며 고민한 점**

- 예약 없이 문진을 작성하거나 예약 센터를 변경하는 경우에도 의료진이 필요한 정보를 확인할 수 있도록 조회 흐름을 보완했습니다.
- 디지털 상품권은 코드 배정과 사용자 표시를 구분하고, 암호화 저장과 마스킹을 적용했습니다.
- 혈액 재고 수치를 보유일수·보유율과 위기 단계로 표현해 사용자가 상태를 이해하기 쉽게 구성했습니다.
